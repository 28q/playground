    入力形式と計算方法

    01 — 式を組み立てる

    自由変数は n。和は sum(式,k,下限,上限)、積は prod(式,k,下限,上限)。ボタンで挿入した式の □ は選択され、そのまま入力できます。選択した部分を和・積などで囲むこともできます。

    sum(binomial(n,k)^2,k,0,n)
Sum[Binomial[n,k]^2,{k,0,n}]
sum(sum(binomial(k,j),j,0,k),k,0,n)
prod((k+1)/k,k,1,n)

    四則演算、^、後置 !、小数、括弧を利用できます。掛け算は必ず * を明示してください。空の和は 0、空の積は 1、0^0 は 1 とします。変数の範囲は和・積の内側だけで有効です。自然言語や LaTeX 入力は未対応です。

    02 — 既知の変形から、値による推測へ

    まず式を構文木として解析し、定数の計算・1 倍や 0 の加算の除去・登録済みの二項和やスターリング和などの恒等式を適用します。次に元の式から整数・有理数の厳密値を計算します。

    多項式係数の線形漸化式 Σⱼ pⱼ(n)a(n+j)=0 を、有理数の連立方程式から探索します。Berlekamp–Massey で定数係数の階数候補を求め、有理数へ持ち上げて厳密に検算します。多項式係数は探索設定の範囲で調べます（未知係数・候補数はいずれも最大36）。既知の数列の和・項別積には閉性を使い、候補を有理関数の恒等式として記号的に検証します。最後の 8 項は係数決定に使わず、検算だけに使います。見つからないことは、その形式の式が存在しないという証明ではありません。

    定数係数の漸化式からは有理型の通常母関数を推測します。それで得られない場合、G(x) の2次・x の2次までの代数方程式を係数比較で探索し、最後の8係数で検算します。辞典に登録した数列は既知の通常母関数（OGF: Σa(n)xⁿ）または指数型母関数（EGF: Σa(n)xⁿ/n!）を表示します。開始 n が 0 以外の場合は母関数を表示しません。

    03 — 高速C++コード

    既定は mod 998244353 の自己完結した C++17 コードです。第N項だけを返す coefficient(N) と、初項からN項までを返す coefficients(N) を選べます。添字は0始まりです。サンプルが途中の添字から始まる推定式では START からの列になり、コード内に明記します。

    有理型母関数の第N項は Bostan–Mori で O(M(r) log N)。係数列は FPS inverse で計算します。ベル数は exp(exp(x)−1)、ベルヌーイ数は x/(exp(x)−1)、オイラー数は 1/cosh(x)、分割数は約数和から作る指数級数を展開します。通常畳み込み・二項畳み込み・二項変換も NTT を使います。M(n)=O(n log n) は多項式乗算の計算量です。

    4階以下の P-recursive の第N項には、多項式行列のブロック積と多点評価を使う baby-step/giant-step（BSGS）を使用します。小さい N は逐次計算、高階は分母の一括反転を使った逐次計算です。列全体は逐次計算します。漸化式の係数が法の上で0になり、埋め込んだ初期項でも解決できない箇所では例外にします。

    FPSによる単項取得は N まで展開して抽出するため、O(log N) ではありません。FPS・列出力は N < 2²¹、P-recursive単項は N < 998244353。有理型単項と多項式単項は、このprefix制限を受けません。未知の式を未検出のまま高速化したことにはしません。

    根拠が「推測」のコードは、未使用の8項で一致していても未証明です。既知の母関数から構成したもの・記号的検証が通ったものと分けて表示します。

    04 — 厳密値のC++コード

    生成コードは C++17 と Boost のヘッダーを使用します。標準入力に最後の添字 N を渡すと、選択した開始 n から N までを出力します。有理数は分数のまま出力し、丸めません。

    g++ -std=c++17 -O2 main.cpp -o main
echo 20 | ./main

    直接計算版は定義と登録済みの恒等式を使います。専用漸化式版は、画面に表示した漸化式と初期値だけを含みます。根拠が「推測」の場合は未証明です。漸化式の最高シフト係数が 0 になる箇所は埋め込んだ初期項で処理し、それ以降で解決できない箇所は例外にします。専用漸化式版の計算は N に対して線形回数の有理数演算ですが、多倍長数の桁数に応じたコストがかかります。

    計算範囲

    評価項数 24〜128、開始 n は 0〜128。通常の名前付き関数の添字は 0〜256、二項係数は −512〜512。有限和・積の端点は −512〜512、最大 513 項。ブラウザーでは演算回数・整数の桁数・実行時間にも制限を設けています。引数の定義域外、ゼロ除算、未対応関数はエラーとして表示します。

    名前のある数列・特殊関数をすべて網羅するシステムではありません。実装済みの関数は辞典に全件掲載しています。無限和・無限積の直接評価、一般的な閉形式の証明、創造的望遠鏡法、多変数の母関数推測、一般のP-recursiveからの微分方程式解法、条件式・合同式の完全な場合分けは未実装です。
