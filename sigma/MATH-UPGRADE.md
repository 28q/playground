# 数学側の拡張（3.2）

## 変形とコード生成

| 入力例 | 利用する変形・計算法 |
| --- | --- |
| `sum(k^3*C(n,k),k,0,n)` | 重みを落下階乗へ展開して和を消去。有理型母関数からBostan–Mori / FPS inverse。 |
| `sum(C(n,k+a)*C(m,k+b),k,-a,n-a)` | 添字を移しVandermondeで `C(n+m,n-a+b)` に変形。4変数の階乗テーブルによるクエリ。 |
| `sum((-1)^k*C(n,k)*k^4,k,0,n)` | 有限差分で、n>4では0になる有限台数列の母関数へ変換。 |
| `sum(k^2*3^k,k,0,n)` | Euler作用素で有理型母関数を構成。Bostan–Mori / FPS inverse。 |
| `sum(k*factorial(k),k,0,n)` | `(k+1)!-k!` を多項式の証明書で検証し、`(n+1)!-1` に変形。専用P-recursive。 |
| `sum(sum(gcd(i,j),j,0,m),i,0,n)` | φを重みとする商の和へ変形。0の軸を補正し、線形篩＋商区間分割。 |
| `sum(fibonacci(k),k,a+1,b+2)` | 式で与えられる区間端点にも累積和を使用。 |

自由変数・クエリ座標は非負整数として扱います。二項係数の上側引数、和の範囲、関数の定義域などを確認してから変形します。和の添字と自由変数のスコープを分離し、矩形・対応する三角形の順序交換、添字の移動・反転、定数因子の取り出しも試します。変形探索は有限の候補に制限しており、同値な式をすべて列挙するものではありません。

重み付き二項和は重みの次数12以下。超幾何項の原始差分は、数値係数の多項式（次数24以下）と非負の一次式を引数とする階乗・非零の定数底の累乗からなる対応形式について、次数12以下の多項式証明書を探します。見つかった証明書の恒等式を厳密に確認します。一般のGosperの正規形や有理関数証明書、パラメータ付き証明書は未実装です。

## 漸化式の探索

階数r・係数次数dの未知係数数は `(r+1)(d+1)`。最大512、既定128です。階数は最大32、次数は最大255、候補数は最大256（既定96）。「指定した階数・次数だけを探索」で大きい候補を直接調べられます。

複数の素数上の線形方程式から候補を得て、CRT・整数または有理数復元で係数を戻します。3個以上、最大48個の素数を使用。最後の8項は係数決定に使用せず、復元後はその8項を含む全項を厳密な有理数で検算します。採用には学習項数−rが未知係数数+2以上必要です。零空間の次元が1になる候補を対象とするため、指定次数が高すぎるなどで一意に定まらない場合は候補を返しません。

評価項数は最大768ですが、関数・有限和の従来の添字上限や演算回数・桁数制限は残ります。探索時間は60秒、Worker全体は120秒まで。これらの上限まで必ず探索が完走するとは限りません。

検証例 `(n+1)^249` は、512項・階数1・次数249・未知係数上限512・指定次数のみの設定で、500未知係数を20素数から復元し、生成C++のn=600を独立計算と照合しました。この経路は有限値からの復元なので、**GUESSED / 未証明**と表示します。

## 母関数の微分方程式と証明状態

P-recursiveから、θ=x d/dx を用いて母関数の微分方程式へ形式的に変換します。開始添字と初期項による右辺の補正を含めます。微分方程式を一般に解いて閉形式を求める機能ではありません。

恒等式・定義・記号的検証を根拠とするコードはPROVEN、有限個の値の一致だけを根拠とするコードはGUESSEDです。推測した漸化式から導いた微分方程式やC++も未証明のままです。

## 今回の範囲外

完全なGosper法、Zeilberger法／creative telescoping、パラメータを含む一般の多変数漸化式探索、一般のD-finite方程式の解法、任意MOD、入力制約に応じた計算法の順位付けは未実装です。提示された改善案全49項目の完了ではなく、数学側を優先した更新です。

原始差分と超幾何項の参考：[SymPyの具体和・Gosperの説明](https://docs.sympy.org/latest/modules/concrete.html)。このアプリはSymPyへの依存を持たず、上記の限定した探索をJavaScriptで行います。
