1. 共通の入力
N
a₁ a₂ … aₙ
mark₁ mark₂ … markₙ
u₁ v₁ w₁
…（N−1本の辺）
頂点番号は1始まり。1 ≤ N ≤ 200,000、−10⁶ ≤ aᵢ ≤ 10⁶、markᵢ は0または1、0 ≤ wᵢ ≤ 10⁶。木は連結であること。使わない a は0、markは0、辺重みwは1で構いません。辺数距離の項目はwを無視します。隣接辺の順序は入力順を保持します。
2. コンパイルして実行
g++ -std=c++17 -O2 generated.cpp -o tree_dp
./tree_dp < input.txt
# Windows: tree_dp.exe < input.txt
GNU g++ または __int128 に対応するClangを使用。外部ライブラリは不要です。MSVC単体には対応しません。数え上げ・行列・写像・ハッシュはMODで計算します。
3. 入力例
3
2 -1 3
1 0 1
1 2 2
2 3 5
重み付き距離和は頂点1から順に9, 7, 12。連結集合数は3, 4, 3。離心率は7, 5, 7です。
出力の読み方
各項目は [項目ID] で始まり、その下にN行の「頂点番号 結果」を出力します。ベクトルは添字順、最適距離は「距離 端点番号 同率個数」、上位K件は「距離:端点番号」。解なし・候補なしはNONE。複数出力の順序はDP共有のためカテゴリの表示順と異なる場合があります。
選択した項目ID意味
全選択と計算量
すべての選択項目を1つのプログラムで実行します。同じ状態・遷移の回答はDPを共有し、異なるDPは順に実行して一時メモリを解放します。時間は各DPの合計、最大メモリは一番大きいDPに依存します。多項式項目はO(NK²)、上位Kや分布はO(NK)です。全選択でNが大きいと、出力量も非常に大きくなります。


全方位化の共通部分
有向辺の向こう側の成分を1つの状態にまとめます。子→親の計算後、親→子を計算。各頂点でprefix/suffixを作り、注目する1本を除いた集約を順序を保って得ます。逆元や除算を使わず、零を含む積にも対応します。再帰を使わないので長いパスでも呼び出しスタックに依存しません。
branches = merge(各隣接成分)
completed = vertex(branches, v)
message = edge(completed, e)
モノイド・作用・一般遷移
枝の集約には結合則と単位元が必要です。可換性は必須ではありません。形式的な作用Tは Tₑ=id、Tₐᵦ=Tₐ∘Tᵦ を満たします。距離の平行移動・線形なモーメント変換・シフトはこの例です。一方、連結集合のx+1、独立集合の状態変換、頂点を含める操作は、一般のDP遷移として扱います。全方位木DPの正しさに、それらが集約モノイドの準同型である必要はありません。
順序に意味がある場合
非可換項目は、各根のDFS先行順を定義してから計算します。頂点を先頭に置き、親以外の隣接頂点を辺の入力順にたどります。親方向から来た状態も元の隣接位置に置きます。アフィン写像の合成順と行列の積順は異なる表記なので、各カードの定義を確認してください。
根によらない項目もある理由
全頂点の和、独立集合総数、最大マッチングの全体値などは根を変えても一定です。教材として掲載し、根を強制選択する条件や有向辺ごとの成分DPへ拡張する足場にしています。完全な数学的列挙ではなく、実装・検証可能な具体例のカタログです。
