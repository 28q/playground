計算設定

入力後、「最適配置を探索して分布計算」を押してください。
計算モデルについて
SectionResult の1000個ソートをそのまま毎回生成すると非常に重いため、順位統計量の分布に置換して高速化しています。status側の順位は Binomial(1000,p)、time側の順位統計量は Beta order statistic からサンプルします。元コードの Random.Range(0.0001,1) によるごく端の切断は標準正規として近似しているため、極端な4σ付近以外では差は非常に小さい想定です。表示確率は外側Monte Carloの推定値です。解析用MC seedは結果再現用で、Unity本体のseedとは無関係です。

解析式

各区の内部statusに同一チーム乱数 R を加え、その値を SectionResultWithMin に渡します。合計分布の計算でも6区に同じ R を共有させています。
1区: .60 S + .20 T + .20 M + δ₁₂ + R
2区: .70 S + .15 T + .15 M + δ₁₂ + R
3区: .45 S + .25 T + .30 M + R
4区: .50 S + .25 T + .25 M + R
5区: .50 S + .25 T + .25 M + δ₅₆ + R
6区: .40 S + .30 T + .30 M + δ₅₆ + R
最適配置は期待タイムのMonte Carlo推定値を使います。僅差（特に0.2秒未満）の候補を厳密に比べたい場合は「高精度」にしてください。
