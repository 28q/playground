呼び出し方
各APIは頂点ごとの結果を vector で返します。result[v] が頂点vの答えです。solve(...) は選択したすべての計算結果をフィールドごとに返し、同じDPを共有します。


グラフと追加の引数
Graph = vector<vector<int>> は0始まりの無向木です。graph[v][j] がvのj番目の隣接頂点です。必要な追加引数だけが各APIの引数に含まれます。


  • edge_weights: vector<vector<long long>> — edge_weights[v][j] を graph[v][j] への辺重みとします。両方向に同じ重みを入れてください。
  • values: vector<long long> — 頂点値a(v)。
  • marks: vector<int> — 頂点の印、0または1。


非可換な計算ではgraphの隣接順を保持します。1 ≤ N ≤ 200,000、|values[v]| ≤ 10⁶、0 ≤ edge_weights[v][j] ≤ 10⁶。不正な入力は std::invalid_argument を投げます。渡した配列は変更しません。


戻り値
スカラーは vector<long long>、距離のモーメントは vector<__int128_t>、分布は vector<array<long long, ...>> です。最適な距離は vector<optional<DistanceResult>> で、distance・vertex・count を返します。上位K件は頂点ごとの vector<pair<long long,int>> です。候補や実行可能解がない値は std::nullopt、空の上位リストは空vectorです。端点番号も0始まりです。

複数項目の計算量
個別APIはそれぞれ木を検証・計算します。solve(...) は木を1回検証し、同じ状態・遷移を共有して計算します。時間は各DPの合計、保存する結果のメモリは各出力の合計です。全108項目の選択では73回のDPを実行します。計算途中のメモリはDPごとに解放します。入力検証のハッシュ表は平均O(N)。多項式はO(NK²)、上位Kや分布はO(NK)です。


全方位化の共通部分
有向辺の向こう側の成分を1つの状態にまとめます。子→親の計算後、親→子を計算。各頂点でprefix/suffixを作り、注目する1本を除いた集約を順序を保って得ます。逆元や除算を使わず、零を含む積にも対応します。再帰を使わないので長いパスでも呼び出しスタックに依存しません。
branches = merge(各隣接成分)
completed = vertex(branches, v)
message = edge(completed, e)
モノイド・作用・一般遷移
枝の集約には結合則と単位元が必要です。可換性は必須ではありません。形式的な作用Tは Tₑ=id、Tₐᵦ=Tₐ∘Tᵦ を満たします。距離の平行移動・線形なモーメント変換・シフトはこの例です。一方、連結集合のx+1、独立集合の状態変換、頂点を含める操作は、一般のDP遷移として扱います。全方位木DPの正しさに、それらが集約モノイドの準同型である必要はありません。
順序に意味がある場合
非可換項目は、各根のDFS先行順を定義してから計算します。頂点を先頭に置き、親以外の隣接頂点を辺の入力順にたどります。親方向から来た状態も元の隣接位置に置きます。アフィン写像の合成順と行列の積順は異なる表記なので、各カードの定義を確認してください。
根によらない項目もある理由
全頂点の和、独立集合総数、最大マッチングの全体値などは根を変えても一定です。教材として掲載し、根を強制選択する条件や有向辺ごとの成分DPへ拡張する足場にしています。完全な数学的列挙ではなく、実装・検証可能な具体例のカタログです。
