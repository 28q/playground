# Sigma Lab

和・積と組合せ数列を厳密に計算し、恒等式による変形、P-recursive 漸化式の推測、母関数の表示、C++17 コード生成を行うローカル Web アプリです。

## 起動

Node.js 18 以上で、このフォルダーから `npm start` を実行し、http://127.0.0.1:4173/ を開きます。追加パッケージのインストールは不要です。`index.html` を直接開くこともできますが、その場合は計算が画面と同じスレッドで動くため、ローカルサーバー経由を推奨します。

## 入力

```text
sum(binomial(n,k)^2,k,0,n)
Sum[Binomial[n,k]^2,{k,0,n}]
sum(stirling2(n,k),k,0,n)
prod(k,k,1,n)
sum(binomial(n,k)^2*binomial(n+k,k)^2,k,0,n)
```

自由変数は n。ボタンで関数や和・積を挿入できます。暗黙の掛け算・自然言語・LaTeX は未対応です。空和=0、空積=1、0^0=1。関数一覧・定義域・規約は画面の辞典とガイドを参照してください。

## 計算方法

- BigInt を使った既約分数による厳密計算。
- 構文木に対する定数畳み込みと登録済みの恒等式。
- Σ p_j(n) a(n+j)=0 の係数を有理数の消去法で推測。階数 ≤ 4、次数 ≤ 3、未知係数 ≤ 12。最後の 8 項を学習から除外し、別途検算。
- 定数係数の漸化式候補から有理型 OGF を構成。見つからない場合は G(x) の2次・x の2次までの代数的 OGF を係数比較で推測し、最後の8係数で独立検算。登録済み数列には既知の OGF/EGF を表示。
- C++17 は Boost.Multiprecision の cpp_int を使い、分数を厳密に計算。直接計算版と、未証明の漸化式を使用する版を出力。漸化式の特異点は直接評価に戻す。

有限個の一致は証明ではありません。推測は明示的に未証明と表示します。任意の名前付き特殊関数や任意の式の閉形式を扱う万能 CAS ではありません。無限和・無限積の評価、一般的な証明、創造的望遠鏡法、剰余体での高速化は実装していません。

## ファイル

- `engine.js`: 厳密数、パーサー、関数レジストリー、恒等式、推測
- `cpp.js`: C++ 生成器と計算ライブラリー
- `app.js`, `style.css`, `index.html`: 画面
- `worker.js`: 解析を画面から分離して実行（20 秒制限）
- `test.cjs`: 値・構文・推測・生成 C++ のテスト

新しい名前付き関数は `CATALOG` と `fn`、C++ 側の `F` に追加してください。ブラウザー側と C++ 側を必ず同時にテストします。
